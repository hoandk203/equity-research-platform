# Từ điển dữ liệu vật lý Oracle v1.0.0

Sinh từ `design/schema_model.json` qua `scripts/design_schema.py`. Không sửa riêng DDL/dictionary. ID NUMBER(19) là surrogate; timestamps có timezone. Tài liệu ERD giải thích các quy tắc ngoài FK/CHECK.

## companies

Pháp nhân, độc lập mã niêm yết

PK: `company_id`. UNIQUE: `company_key`; `tax_code`.

| Cột | Kiểu Oracle | NULL? | Default | Ý nghĩa |
|---|---|---|---|---|
| company_id | NUMBER(19) | NO | — | Surrogate ID, identity GENERATED BY DEFAULT ON NULL |
| company_key | VARCHAR2(40 CHAR) | NO | — | Mã nội bộ bất biến |
| company_name | VARCHAR2(250 CHAR) | NO | — | Tên doanh nghiệp |
| tax_code | VARCHAR2(30 CHAR) | YES | — | Mã thuế khi đã xác minh |
| created_at | TIMESTAMP WITH TIME ZONE | NO | SYSTIMESTAMP | Thời điểm tạo |

| Cột | Kiểu Oracle | NULL? | Default | Ý nghĩa |
|---|---|---|---|---|
| artifact_id | NUMBER(19) | NO | — | Surrogate ID, identity GENERATED BY DEFAULT ON NULL |
| source_id | NUMBER(19) | NO | — | Nhà cung cấp/đơn vị phát hành |

## financial_reports

Phiên bản một loại BCTC của một kỳ/phạm vi

PK: `report_id`. UNIQUE: `company_id, fiscal_year, period_kind, statement_kind, scope_code, artifact_id, mapping_version, report_version`; `report_id, statement_kind`.

| Cột | Kiểu Oracle | NULL? | Default | Ý nghĩa |
|---|---|---|---|---|
| report_id | NUMBER(19) | NO | — | Surrogate ID, identity GENERATED BY DEFAULT ON NULL |
| company_id | NUMBER(19) | NO | — | Doanh nghiệp |
| fiscal_year | NUMBER(4) | NO | — | Năm báo cáo |
| period_kind | VARCHAR2(10 CHAR) | NO | 'ANNUAL' | Năm trong MVP |
| statement_kind | VARCHAR2(2 CHAR) | NO | — | BS/IS/CF |
| scope_code | VARCHAR2(16 CHAR) | NO | 'UNKNOWN' | Phạm vi canonical |
| source_report_type | VARCHAR2(20 CHAR) | NO | — | Mã nguồn HK/... |
| artifact_id | NUMBER(19) | NO | — | Artifact gốc |
| mapping_version | VARCHAR2(40 CHAR) | NO | — | Mapping đã dùng |
| report_version | NUMBER(6) | NO | 1 | Phiên bản kể cả review metadata |
| fiscal_start | DATE | YES | — | Ngày đầu niên độ xác minh |
| fiscal_end | DATE | YES | — | Ngày cuối niên độ xác minh |
| publication_at | TIMESTAMP WITH TIME ZONE | YES | — | Thời điểm công bố có bằng chứng |
| publication_artifact_id | NUMBER(19) | YES | — | Bằng chứng công bố |
| currency_code | VARCHAR2(7 CHAR) | NO | 'UNKNOWN' | VND/UNKNOWN |
| original_unit | VARCHAR2(20 CHAR) | NO | 'UNKNOWN' | VND/THOUSAND_VND/MILLION_VND/UNKNOWN |
| unit_multiplier | NUMBER(10) | YES | — | Hệ số sang VND sau xác minh |
| metadata_status | VARCHAR2(12 CHAR) | NO | 'PENDING' | Scope/fiscal/unit đã kiểm chứng? |
| batch_id | NUMBER(19) | NO | — | Batch nhập |

- FK `company_id` → `companies(company_id)`.
- FK `artifact_id` → `source_artifacts(artifact_id)`.
- FK `publication_artifact_id` → `source_artifacts(artifact_id)`.
- FK `batch_id` → `etl_batches(batch_id)`.
- CHECK `statement_kind IN ('BS','IS','CF')`.
- CHECK `scope_code IN ('UNKNOWN','CONSOLIDATED','SEPARATE')`.
- CHECK `period_kind = 'ANNUAL'`.
- CHECK `fiscal_year BETWEEN 1900 AND 2200`.
- CHECK `report_version > 0`.
- CHECK `metadata_status IN ('PENDING','VERIFIED')`.
- CHECK `(fiscal_start IS NULL AND fiscal_end IS NULL) OR (fiscal_start IS NOT NULL AND fiscal_end IS NOT NULL AND fiscal_end >= fiscal_start)`.
- CHECK `unit_multiplier IS NULL OR unit_multiplier IN (1,1000,1000000)`.
- CHECK `(publication_at IS NULL AND publication_artifact_id IS NULL) OR (publication_at IS NOT NULL AND publication_artifact_id IS NOT NULL)`.
- CHECK `metadata_status <> 'VERIFIED' OR (scope_code <> 'UNKNOWN' AND fiscal_start IS NOT NULL AND fiscal_end IS NOT NULL AND currency_code = 'VND' AND original_unit <> 'UNKNOWN' AND unit_multiplier IS NOT NULL)`.

| statement_kind | VARCHAR2(2 CHAR) | NO | — | Khóa lan truyền để ngăn item sai statement |
| value_text | VARCHAR2(200 CHAR) | YES | — | Giá trị nguồn dạng text |
| value_original | NUMBER(38,6) | YES | — | Số nguồn |
| value_vnd | NUMBER(28,0) | YES | — | Số VND chỉ sau xác minh đơn vị |

## daily_prices

Giá ngày có phiên bản nguồn; chưa có dataset nghiệm thu

PK: `price_id`. UNIQUE: `security_id, trading_date, artifact_id, price_basis`.

| Cột | Kiểu Oracle | NULL? | Default | Ý nghĩa |
|---|---|---|---|---|
| price_id | NUMBER(19) | NO | — | Surrogate ID, identity GENERATED BY DEFAULT ON NULL |
| security_id | NUMBER(19) | NO | — | Chứng khoán |
| trading_date | DATE | NO | — | Ngày giao dịch không có phần giờ |
| artifact_id | NUMBER(19) | NO | — | Nguồn phiên bản |
| price_basis | VARCHAR2(12 CHAR) | NO | — | ADJUSTED/UNADJUSTED/UNKNOWN |
| currency_code | VARCHAR2(7 CHAR) | NO | — | VND/UNKNOWN |
| price_multiplier | NUMBER(10) | YES | — | Hệ số sang VND |
| open_price | NUMBER(20,6) | YES | — | Giá mở cửa |
| high_price | NUMBER(20,6) | YES | — | Giá cao |
| low_price | NUMBER(20,6) | YES | — | Giá thấp |
| close_price | NUMBER(20,6) | NO | — | Giá đóng cửa |
| volume | NUMBER(24,0) | YES | — | Khối lượng |

- FK `security_id` → `securities(security_id)`.
- FK `artifact_id` → `source_artifacts(artifact_id)`.
- CHECK `price_basis IN ('ADJUSTED','UNADJUSTED','UNKNOWN')`.
- CHECK `trading_date = TRUNC(trading_date)`.
- CHECK `close_price >= 0`.

- CHECK `low_price IS NULL OR open_price IS NULL OR low_price <= open_price`.
